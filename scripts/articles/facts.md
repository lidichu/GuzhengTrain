## 二、古箏基本事實（已查證）

- 現代最常用的是 **21 弦**古箏，另有 16、18、26 弦等規格。（維基百科〈古箏〉）
- 21 弦古箏通常依 **D 大調五聲音階**定弦。（維基百科〈古箏〉）
- 演奏時普遍配戴**義甲**，以膠布纏繞固定。（維基百科〈古箏〉）
- 右手在琴碼右側彈弦，**左手在琴碼左側**按弦作韻（按、滑、顫）。（維基百科〈古箏〉）
- 古箏屬於固定音高樂器，定好弦後每根弦對應一個音。

## 三、右手八法（主流定義，本站已依此更正過舊文章）

方向定義：**「內」＝靠近演奏者的一側（往高音）；「外」＝遠離演奏者的一側（往低音）**。
口訣：**抹、勾、劈、打向內；挑、剔、托、摘向外。**

| 指法 | 手指 | 方向 |
|---|---|---|
| 托 | 大指（拇指） | 向外 |
| 劈 | 大指 | 向內 |
| 挑 | 食指 | 向外 |
| 抹 | 食指 | 向內 |
| 剔 | 中指 | 向外 |
| 勾 | 中指 | 向內 |
| 摘 | 無名指 | 向外 |
| 打 | 無名指 | 向內 |

### 容易寫錯的觀念（本站曾經寫錯，務必避免）
- **抹**不是「大指連續托多弦」——那是**刮奏／花指**。抹是食指向內撥弦。
- **摘**不是「大指與食指同時彈兩音」——那是**小撮**。摘是無名指向外撥弦。
- **勾**專指**中指**，不是食指、無名指皆可。**挑**專指**食指**。
- **搖指（Tremolo）**：大指（或食指）在同一根弦上快速往復（劈托、抹挑），形成持續長音。是**右手**技巧。
- **顫音（Vibrato，又稱揉弦）**：右手彈弦後，**左手**在琴碼左側作垂直起伏按動，使音高規律波動。是**左手**技巧。
  → 兩者經常被混淆，寫作時絕不可對調。
- **輪指**：多指在同一弦上依序輪流撥弦，與搖指是不同技巧。
- **大撮**：大指與中指同時彈奏，多為八度和音。**小撮**：大指與食指同時彈奏，多為五度以內和音。
